## 💰 تحليل نقطة التعادل (Break-Even)

### 📊 حساب نقطة التعادل الشهرية

**المصاريف الثابتة الشهرية**:
| البند | المبلغ |
|-------|:---:|
| إنترنت + هاتف | 200 د.م |
| كهرباء + ماء | 150 د.م |
| متفرقات | 200 د.م |
| **المجموع** | **550 د.م** |

**المتغيرات لكل طلب**:
| البند | المبلغ |
|-------|:---:|
| تكلفة المنتجات (68%) | 61.20 د.م |
| تكلفة التوصيل | 8 د.م |
| مواد تغليف | 2 د.م |
| ضرائب (1%) | 0.90 د.م |
| **المجموع** | **72.10 د.م** |

**هامش المساهمة**: 90 د.م (إيراد) - 72.10 د.م (متغيرات) = **17.90 د.م/طلب**

**نقطة التعادل**: 550 ÷ 17.90 = **31 طلب/شهر** ≈ **1.2 طلب/يوم**

🎯 **الخلاصة**: يكفي **2 طلبات يومياً** للوصول إلى التعادل الشهري!
