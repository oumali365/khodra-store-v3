# دليل صور أقسام المتجر (Categories)

ضع الصور بصيغة **`.webp`** بالأسماء التالية في هذا المجلد (`public/images/categories/`):

1. **`all.webp`** -> قسم: الكل
2. **`vegetables.webp`** -> قسم: خضروات
3. **`fruits.webp`** -> قسم: فواكه
4. **`dairy.webp`** -> قسم: ألبان وأجبان
5. **`grocery.webp`** -> قسم: بقالة ومونة
6. **`drinks.webp`** -> قسم: عصائر ومشروبات
7. **`cleaning.webp`** -> قسم: نظافة وعناية

بمجرد وضع الصور بهذه الأسماء، ستظهر تلقائياً في شريط الفئات.
إذا لم تكن الصورة موجودة، سيعرض المتجر تلقائياً الأيقونة التعبيرية المناسبة بدون أي خطأ.
